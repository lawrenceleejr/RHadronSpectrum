# RHadronSpectrum

Lattice QCD calculation of the R-hadron mass spectrum (bound states of a heavy gluino
with gluons and quarks) in the static-gluino limit, valid for m_gluino ~ 1 TeV, with the
aim of identifying the lightest state.

- [`PLAN.md`](PLAN.md) — physics formulation, methods, ensembles, HTCondor execution
  model, milestones with gates, verification.
- [`CLAUDE.md`](CLAUDE.md) — conventions for the agent executing the plan.
